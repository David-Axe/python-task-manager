# Gerenciador de Tarefas

Um gerenciador de tarefas via linha de comando (CLI) feito em Python para gerenciar suas atividades diárias com prioridades.

## Como Executar

```bash
python task_manager.py
```

## Funcionalidades

- Adicionar tarefas com título e prioridade (alta/média/baixa)
- Listar todas as tarefas
- Marcar tarefas como concluídas
- Remover tarefas
